## Usage

1. 테마와 스타일을 선택한다.
2. GitHub username을 입력한다.
3. 생성된 마크다운을 `README.md`에 붙여넣는다.

### Flower

꽃 종류와 색상을 커스터마이징할 수 있습니다.

**Types**: `default`(Daisy), `tulip`, `sunflower`, `cherry`

**Query Parameters**

| Param | Description | Default |
|-------|-------------|---------|
| `flower` | 꽃 종류 | `default` |
| `color` | HEX 색상 코드 | `#fbbf24` |
